dbgit — try it in the browser

dbgit is version control for a database schema, the way git is version control for code: you fork an isolated branch database, stage schema changes (DDL statements like CREATE TABLE), commit them, and later diff or merge branches. It supports several SQL dialects (Postgres, MySQL, H2) - this particular deployment is set up to talk to Postgres, but nothing below is Postgres-specific to dbgit itself. Normally you'd do all of this from a terminal with the ./dbgit command-line tool talking to a background daemon (./dbService). This page is that same tool - every field below sends the exact same request a terminal would, just filled in with a form instead of typed by hand.

the command field literally what you'd type after ./dbgit - typing checkout -b feature here is the same as running ./dbgit checkout -b feature
the DDL body box what you'd normally pipe in on stdin, e.g. echo "CREATE TABLE t (id INT);" | ./dbgit add

All dbgit commands, with an example of each



CommandExampleWhat it does


init(already done in Step 1 above)
    Points main at a real database. One-time setup, not a day-to-day command.


branchdbgit branch
    Lists every branch that exists, marking the one you're currently on with *. A
        good first command to run.


checkout -bdbgit checkout -b my-feature
    Forks the branch you're on into a brand new one (a real, independent database) and switches
        to it - like git checkout -b.


checkoutdbgit checkout main
    Switches to a branch that already exists.


adddbgit add (with a statement in the DDL body box below,
        e.g. ALTER TABLE orders ADD COLUMN total INT;)
    Stages one schema change and applies it to your current branch right away - like
        git add, but for a table definition instead of a file.


commitdbgit commit -m "add total column"
    Folds everything you've added so far into one commit on your current branch.


logdbgit log
    Shows your current branch's commit history, newest first, plus anything staged but not yet
        committed.


diffdbgit diff main my-feature
    Shows exactly what's different between two branches' schemas - which tables/columns changed,
        and which side changed them.


mergedbgit merge my-feature (run while checked out on the
        branch you want to merge into)
    Brings another branch's changes into your current one. Refuses if both branches changed the
        same thing in conflicting ways.


resetdbgit reset 3
    Takes your current branch back to an earlier commit, rebuilding its database to match.
        Refused on main.


helpdbgit help or dbgit help diff
    Prints this same list (or detail on one command) as dbgit's own output, right in the Response
        box below - handy if this table ever falls out of date.
